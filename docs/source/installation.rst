Installation
============

OpenSTRAN is available on PyPI and can be installed using pip. It is recommended to install OpenSTRAN in a virtual environment.

Installation from PyPI
-----------------------

.. code-block:: bash

   pip install OpenSTRAN

Dependencies
------------

OpenSTRAN depends on the following packages:

* `scipy <https://scipy.org/>`_ - used for vector and matrix mathematical operations.
* `numpy <https://numpy.org/>`_ - used by scipy.

Installing OpenSTRAN will automatically install these packages by default.

Requirements
------------

* Python 3.14 or higher
